# S Engine 3.0.0 — final APK deliverables

This directory contains the installable Android APKs produced by the **Build S Engine 3.0.0 APK** workflow (manual `workflow_dispatch` or `[publish-apk]` publish job) from the Professional Studio Edition source tree.

| File | Purpose |
|---|---|
| `SEngine-3.0.0-debug.apk` | Debug build of the full engine/editor with both reference games |
| `SEngine-3.0.0-release.apk` | Release build, debug-key signed so it installs immediately |
| `SHA256SUMS.txt` | Checksums generated by CI for both APKs |

Both APKs are verified by CI as valid ZIP archives containing `classes.dex`, `AndroidManifest.xml` and `resources.arsc`. Replace the release signing configuration with your own key before publishing to an app store.

Minimum Android version: 8.0 (API 26). Requires OpenGL ES 2.0.
